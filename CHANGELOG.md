# Changelog

## Save As compatibility — 2026-10-21

Replace Hidden-attribute cleanup with desktop-only presentation and a desktop child launcher. Original folders remain visible in Save As and Explorer; automatic collection indexes without changing attributes. Add legacy-attribute restoration and regression checks.


## 0.1.0 — 2026-10-21

Initial public prototype: three spatial groups, native animated WPF launcher, original Shell icons and original paths, reversible desktop hiding, opt-in automatic collection and login startup. Includes generic desktop initialization, synthetic integration tests and design rationale. Personal installation data is excluded.
