# 设计思路：把展示与存放分开

这个项目最先要解决的不是“图标应该画成什么风格”，而是桌面整齐和原路径稳定之间的冲突。用户希望保留已经形成的操作记忆：去桌面保存、按旧图标辨认、从熟悉的位置找入口，自动化继续引用同一个位置。

## 1. 先理解“左、中、右”

左边栏、中间栏、右边栏来自用户原来摆放图标的物理区域。它们不是“工具、资料、业务”的代称。擅自按功能重新分类，即使分类看起来合理，也会破坏用户已有的空间记忆。

公开原型用桌面宽度三等分提供初始分区，并保留行优先顺序；对于不规则分组或多屏布局，允许在首次初始化时提供本地布局文件。算法只是初始建议，用户的安排是依据。

## 2. 美观不必从重画所有图标开始

原图标承载了用户的识别习惯，包括应用标记、文件类型以及文件夹预览。重新换一套统一图标可能降低查找效率。

因此保留 Windows Shell 给出的原图像，只设计收纳程序自身的入口。统一的是留白、字号、图标尺寸、对齐、焦点和动效节奏。长文件名在格子里省略，但原名、源路径和提示保留。

## 3. 收纳入口引用原件

原文件留在桌面原路径。收纳目录生成快捷方式，运行时同时保存原来源，点击后执行原入口。业务原件不会因为界面“归类”而搬动。

空间层与存储层由此可以分别变化：视觉上只剩一个入口，原文件仍能被既有程序按完整路径访问。原文件的可见属性也必须保持。旧Hidden方案让另存为窗口找不到原目录，已被撤换；原路径不变并不等于保存体验不受影响。

## 4. 隐藏需要可恢复

当前使用Windows桌面视图的FWF_NOICONS关闭原生图标显示，同时显示以桌面宿主为owner的独立顶层入口，沿用本项目图标和名称。透明WPF子窗口在实机上未实际显示，已经撤换。入口的Z序保持紧邻桌面宿主上方、普通窗口下方；通过WM_WINDOWPOSCHANGING限制焦点和系统抬高请求，并保持owner层级不变。点击桌面后调用HWND_TOP会把非置顶入口也抬到普通窗口前面，这一补救已撤换。不能仅凭Topmost=false判断不会覆盖其他窗口，也不能仅凭Visible判断用户看到了入口。

按住入口并超过系统拖动阈值后即可移动；松开后保存位置，不打开面板。桌面入口位置.json保存本机坐标，重启及桌面重建后恢复，并限制在工作区内；配置损坏时恢复默认位置。它不移动原快捷方式，不改原路径。

文件和目录本身保持正常可见，另存为与普通资源管理器不受桌面视图设置影响。退出/恢复时显示原生桌面；恢复先暂停自动收纳。显示层异常时优先恢复原生桌面，不隐藏文件。

旧隐藏属性快照只用于一次性迁移。禁止在日常收纳或自动收纳中设置原文件Hidden位，也不以全局显示隐藏文件补救。旧FilterView尝试在桌面刷新后不可靠，不能据一次未刷新的条目计数宣称成功。

## 5. 动效帮助理解进入与返回

入口可选择扇形或网格展开，三栏仍是实际的导航目录。点击分类进入下一层，Esc 返回，外部点击收回；快速关闭和重开能中断上一段动画。

展开主要用位移、缩放和透明度表达来源，不旋转原图标。尊重系统减少动画偏好，支持键盘焦点。子页随内容增长，受屏幕工作区限制，必要时滚动。

## 6. 新文件沿用已有模型

新保存的桌面项目只增加入口。保存稳定、没有写入占用后持久化导航；不改原属性，默认追加左边栏末尾。改变默认栏只影响以后新增项目。

Windows 文件标识用于匹配改名。原件被用户删除或移出桌面时，只移除本工具的导航。临时、下载中、系统和未跟踪的原隐藏文件跳过。自动收纳及登录启动均由用户主动启用。

## 当前取舍

用户可在栏内进入“选择”，勾选多项后删除，也可右键移到回收站或按Delete；普通点击继续打开。确认区在同一面板底部列出原名称与原路径，默认焦点在取消，说明文件夹内容会一并回收、快捷方式不删除目标。Esc优先取消确认或退出选择。分类及系统入口不可删除。

回收使用IFileOperation的强制回收和撤销记录；拒绝永久删除路径，不自动提权。确认期间源元数据变化、占用或原生失败时保留并反馈。静态导航和历史布局保留，只隐藏不存在的原项目，恢复原路径后重新显示。自动项目沿用原索引回收机制。测试只能回收自建合成文件，不能触碰真实桌面资料。

- 原生 WPF / .NET Framework，沿用 Windows Shell，不引入浏览器界面或联网服务。桌面显示层只作用于当前桌面，另存为保持原目录可见。
- 快捷方式读写明确采用 Windows 的 IShellLinkW Unicode 接口，保留中文路径、工作目录与参数，不依赖系统 ANSI 代码页。
- 公开版移除个人桌面清单、业务命名、缓存、录屏、账号与路径。
- 当前以 Windows 10 单屏桌面验证为主；多屏、混合 DPI 和 Windows 11 需要社区验证。
- 当前不是文件备份、文件管理器替代品或跨设备同步工具。

产品构思与方向由项目发起者提出，代码实现使用 AI 辅助。本文记录最终被确认的设计，不把早期误解或代理偏好当作用户要求。
